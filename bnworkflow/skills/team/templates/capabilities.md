# 角色能力表

> 每位成員另具 `bnworkflow:team`；只讀自己角色那列，不載入全表內容。這是角色應使用的 workflow skills，不代表其他 skill 被卸載。

| 角色代號 | 核心 skills |
|---|---|
| CTO | `do`、`review`、`verify`、`status` |
| PM | `make-req`、`make-spec`、`status`、`verify-pm` |
| PO | `make-req`、`make-spec`、`verify-pm` |
| BIZ-ARCH | `make-req`、`make-spec`、`review-business` |
| SYS-ARCH | `make-design`、`review-system`、`review-security` |
| PROG-ARCH | `make-design`、`make-plan`、`review-program` |
| SA | `make-req`、`make-spec`、`make-testplan`、`review-sa` |
| SD | `make-plan`、`make-code`、`review-code`、`review-security` |
| UIUX | `make-spec`、`make-testplan`、`review-uiux`、`verify-e2e` |
| PG | `make-code` |
| SRE | `make-design`、`review-infra`、`verify-deploy`、`verify-e2e` |
| SQA | `make-testplan`、`verify` |
| SEC | `review-security`、`verify-security-officer` |
